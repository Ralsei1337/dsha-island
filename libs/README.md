# libxposed API

`libxposed-api-102.jar` is `classes.jar` extracted from the Maven artifact
`io.github.libxposed:api:102.0.0` (AAR), used as a `compileOnly` dependency for
the SystemUI module.

- Project: https://github.com/libxposed/api
- License: Apache-2.0

It is not bundled into the built module APK; LSPosed provides the implementation
at runtime.
