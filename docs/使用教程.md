## 1. 选哪条路

| 你的设备 | 安装什么 | 能显示什么 |
|---|---|---|
| Xiaomi HyperOS 3/4，有 root + LSPosed | 模块 APK + 插件 | 官方大岛：动作 + 路径/命令 + 当前动作耗时 + 任务总耗时 + 停止按钮 |
| Xiaomi HyperOS 3/4，无 root | Lite APK + 插件 | 胶囊：图标 + 动作 + 内容 |
| OPPO / 一加 / realme ColorOS 16（Android 16） | Lite APK + 插件 | 流体云（AOSP Live Updates） |
| vivo / iQOO OriginOS（Android 16） | Lite APK + 插件 | 原子通知（仅当系统实现 Live Updates，否则普通通知） |
| Huawei HarmonyOS 4（Android 底） | Lite APK + 插件 | 只能普通通知，Android APK 不能用实况窗 |
| Huawei HarmonyOS NEXT | 不支持 | 不能安装 APK |

> root 模块只对 Xiaomi 生效；其他品牌装了也会自动 inactive，不会被 hook。

## 2. 准备

1. 安装 DSHA，确认包名是 `dsh.android.client`；
2. 从 [Release](https://github.com/Ralsei1337/dsha-island/releases) 下载对应 0.3.1 文件：
   - `dsha-island-0.3.1.apk`（root 模块）
   - `dsha-island-lite-0.3.1.apk`（免 root 伴生 App）
   - `dsh-island-lite-0.3.1.tar.gz`（DSHA 插件，两条路都要）
3. 手机目录整理后的位置：`Download/DSHA/DSHA-Island/01-当前/`。

## 3. root + LSPosed 安装

### 3.1 安装模块 APK

用文件管理器打开 `dsha-island-0.3.1.apk`，允许安装。

### 3.2 在 LSPosed 中启用

1. 打开 LSPosed 管理器 → 模块；
2. 勾选 **DSHA Island**；
3. 作用域**只勾** `com.android.systemui`；
4. 不要勾 `dsh.android.client`（模块不进入 DSHA 进程）。

### 3.3 重启

**重启手机**（或 LSPosed 的软重启）。  
模块的 dex 只在 SystemUI 进程启动时加载，不重启不会生效。

### 3.4 安装 DSHA 插件

1. 打开 DSHA → 插件页；
2. 选择安装本地插件包，选 `dsh-island-lite-0.3.1.tar.gz`；
3. 安装后重启一次 DSH（不是只刷新网页）。

插件会：
- 监听 `session/event`；
- 在 `127.0.0.1:8797/state` 暴露当前状态；
- 模块每秒读取这个接口。

### 3.5 确认模块已加载

有电脑 adb 时：

```bash
adb logcat -s DshaIsland
```

期望看到：

```text
SystemUI loaded, installing DSHA island hooks
hooked MiuiBaseNotifUtil.generateInnerNotifBean
hooked NotificationSettingsManager#canShowFocus
hooked SignatureChecker#checkSignatures
```

早期出现 `pipeline hook missing` 是正常的，模块会从插件 ClassLoader 再挂一次。

## 4. 免 root Lite 安装

### 4.1 安装 APK

打开 `dsha-island-lite-0.3.1.apk` 安装。

### 4.2 授权并启动

1. 打开 **DSHA Island Lite**；
2. 允许通知；
3. 点「启动岛服务」；
4. 状态页应显示：
   - 通知权限：已开
   - 岛服务：运行中
   - 平台：`Xiaomi/OPPO/vivo/... · Android 16 · 流体云 · Live Updates 可用`
   - 监听：`127.0.0.1:8798`

### 4.3 安装插件

同 3.4，安装 `dsh-island-lite-0.3.1.tar.gz`，重启 DSH。

### 4.4 平台注意

- **OPPO / 一加 / realme**：需要 ColorOS 16（Android 16）。系统设置里允许通知、关闭省电限制。
- **vivo / iQOO**：只有系统实现 Android 16 Live Updates 才会出现原子通知；否则只是普通通知。
- **Huawei HarmonyOS 4**：Android 应用不能使用实况窗，只能普通通知。
- **HarmonyOS NEXT**：不能安装 APK，本方案不适用。

## 5. 跑一个任务

1. 回桌面，让 DSHA 保持在后台；
2. 在 DSHA 里发一个会调用工具的任务，例如「读取 README 并写一个测试文件」；
3. 看状态栏顶部：
   - 思考时：`思考中`
   - 读文件：`读取 /path`
   - 写文件：`写入 /path`
   - 执行命令：`执行命令`
   - 清单：`清单 1/2 ...`
   - 完成：`任务完成`（约 8 秒后收起）

展开岛/通知卡片应看到：
- 当前动作耗时；
- `任务总耗时 X`；
- 一个「停止」按钮。

> 任务结束那一刻不要停在 DSHA 前台。DSHA 检测到自己在前台会主动取消任务通知，模块无法拦截。

## 6. 验证是否生效

### 6.1 看模块日志

```bash
adb logcat -s DshaIsland
```

正常更新示例：

```text
enriched phase=TOOL short=写入 /root/x.java src=direct ...
enriched phase=TOOL short=执行 sleep 15 src=direct ...
enriched phase=DONE_OK short=任务完成 src=direct ...
```

- `src=direct`：详情来自插件 8797（最完整）；
- `src=bridge`：来自 Lite 桥接通知（可选备用）；
- `src=notif`：只从 DSHA 通知拿到阶段/总秒数，没有路径。

### 6.2 看插件状态接口

手机上有 Termux/curl 时：

```bash
curl -s http://127.0.0.1:8797/state
```

期望类似：

```json
{"state":"writing","text":"/root/x.java","startedAt":1793037351715,"aliveAt":1793037352425}
```

`aliveAt` 每秒更新；超过 12 秒不更新，模块会认为插件失联并降级。

### 6.3 看 LSPosed 日志

```bash
adb shell su -c "ls -lt /data/adb/lspd/log | head"
```

最新 `modules_*.log` 里搜索 `DshaIsland`。

## 7. 排错

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 完全没有岛 | 模块没启用/没重启 | LSPosed 勾选 + 作用域 SystemUI + 重启手机 |
| 完全没有岛 | DSHA 在前台 | 回桌面再跑；DSHA 前台会 cancel 通知 |
| 完全没有岛 | 通知权限关闭 | 设置 → 应用 → DSHA → 通知 → 允许 |
| 两个岛 | 旧版模块或同时开了 Lite/WorkIsland | 升级 0.3.1+；停掉 Lite（或开 root 桥接模式）与 WorkIsland |
| 卡住不更新 | 旧版模块遇到旧 param 直接 return | 升级 0.3.1+；重启 SystemUI |
| 卡住不更新 | 插件 8797 进程失联 | 重启 DSH；看 `curl 8797/state` 的 `aliveAt` |
| 路径时有时无 | 8797 短暂不可达，回退 DSHA 通知 | 升级 0.3.1+（12 秒缓存 + 心跳）；检查插件是否加载 |
| 日志 `src=notif` | 插件没运行/8797 连不上 | DSHA 插件页确认 `dsh-island-lite` 已加载；重启 DSH |
| 没有「停止」 | 旧版或卡片未展开 | 升级 0.1.5+；点开岛卡片 |
| 完成后无通知 | 旧版过滤了终态摘要 | 升级 0.1.7+ |
| 模块日志 `non-Xiaomi device` | 在 OPPO/vivo/华为装了 root 模块 | 正常 inactive；改用 Lite |
| 华为没有实况窗 | Android APK 不支持 | 只能普通通知；HarmonyOS NEXT 不能装 APK |
| OPPO 没有流体云 | 系统低于 ColorOS 16 / 未允许通知 | 升级系统；检查通知权限和 Fluid Cloud 设置 |

## 8. 卸载 / 回滚

### root 模块

1. LSPosed 停用 **DSHA Island**；
2. 重启手机；
3. 需要的话卸载 APK。

### Lite

1. 打开 Lite → 停止岛服务；
2. 卸载 APK；
3. DSHA 插件页卸载 `dsh-island-lite`。

回滚后 DSHA 本身不受影响；本方案不改 DSHA 的文件/签名/数据。

## 9. 从源码构建

### 模块

```bash
cd dsha-island
./build.sh
# 产物：out/current/dsha-island-0.3.1.apk
```

### Lite

```bash
cd dsha-island/lite
./build.sh
# 产物：out/current/dsha-island-lite-0.3.1.apk
```

### 插件

```bash
cd dsha-island
rm -rf /tmp/dsh-island-lite
cp -r plugin /tmp/dsh-island-lite
tar -czf out/current/dsh-island-lite-0.3.1.tar.gz -C /tmp dsh-island-lite
```

依赖：Android SDK platform 37、build-tools 37、JDK 17+、aarch64 aapt2（本机路径见 README 第 5 节）。
